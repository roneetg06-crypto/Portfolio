## 📂 Featured Projects

### 1. 🏛️ [AI Bureaucracy Copilot (JanSevaAI)](./AI-Bureaucracy-Copilot)
- **Description**: Full-stack AI-powered civic assistant simplifying complex Indian government welfare schemes and administrative paperwork into plain, accessible English and Hindi.
- **Key Features**:
  - Multi-Agent Orchestration via LangGraph (Supervisor, Intake, Eligibility, Scheme Comparison, Document Formatter).
  - Realistic Mock Government Portal with interactive citizen walkthroughs.
  - Eligibility analyzer, grievance letter generator, and document checklist generator.
  - Multi-language voice query integration (Speech-to-Text & Text-to-Speech).
- **Tech Stack**: FastAPI, React 18, TypeScript, Tailwind CSS, LangGraph, Google Gemini, PostgreSQL, pgvector, Docker.
