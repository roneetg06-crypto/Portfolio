# Food Delivery ETL Project

This project builds a simple ETL workflow for food delivery order data and prepares it for business analysis. The goal is to turn messy raw order records and weather information into a clean, analysis-ready dataset that can answer questions about customer behavior, delivery performance, and weather impact.

## Project Objective

The project focuses on three main stages:

1. Loading raw data from order records and weather information.
2. Cleaning and standardizing the data for consistency.
3. Analyzing the final dataset to uncover patterns such as repeat orders, popular meal times, restaurant preferences, and the effect of rainy weather.

## Data Sources

- Raw orders data: data/raw/orders_messy.csv
- Weather data: data/raw/weather_data.csv
- Processed analysis dataset: data/processed/orders.csv

## Project Structure

- data/raw/ - original input files before cleaning
- data/processed/ - cleaned and merged dataset used for analysis
- data/notebooks/ - Jupyter notebooks for each stage of the pipeline
- data/docs/ - project documentation

## Notebook Workflow

Use the notebooks in this order:

1. project_2_loading.ipynb
   - Loads the raw order and weather data.
   - Creates the merged dataset for downstream use.

2. project_2_cleaning.ipynb
   - Handles missing values and inconsistent fields.
   - Standardizes columns such as city, meal type, and weather labels.
   - Produces a cleaned dataset.

3. project_2_analysis.ipynb
   - Runs SQL-based analysis on the cleaned data.
   - Answers business questions such as:
     - How many total orders were received?
     - Which meal time has the highest demand?
     - Which restaurant type gets the most orders?
     - Do rainy conditions affect order volume?
     - Which cities generate the most revenue?

## Key Business Questions Covered

This project is designed to support insights around:

- Order volume and customer demand
- Popular cuisines and meal types
- Repeat-order behavior
- Revenue contribution by city
- Weather-related ordering patterns
- Delivery experience and service expectations

## Output Files

The main output generated by the pipeline is:

- data/processed/orders.csv

This file contains the final merged and cleaned dataset with order details and weather-related features.
