# 📊 Sales Analysis using PostgreSQL & Python

## 📌 Project Overview

This project demonstrates how to perform sales data analysis by connecting **Python** with a **PostgreSQL** database. Instead of analyzing data directly from a CSV file, all business insights are generated using SQL queries executed from Python.

The project simulates a real-world data analytics workflow where data is stored in a relational database, queried using SQL, and visualized using Python.

---

## 🎯 Objectives

* Clean and prepare the sales dataset.
* Store the cleaned data in a PostgreSQL database.
* Execute SQL queries using Python.
* Generate meaningful business insights.
* Create visualizations for better decision-making.
